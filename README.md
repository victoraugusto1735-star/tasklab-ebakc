# TaskLab

Projeto simples de lista de tarefas feito com Next.js 15 para praticar testes unitários.

---

## Tecnologias usadas

* Next.js
* TypeScript
* Jest
* Testing Library

---

## O que o projeto faz

* Mostra uma lista de tarefas
* Permite adicionar novas tarefas
* Conta a quantidade de tarefas com um hook
* Tem testes para as principais funcionalidades

---

## Como rodar o projeto

Instalar dependências:

```bash
npm install
```

Rodar o projeto:

```bash
npm run dev
```

Abrir no navegador:

http://localhost:3000

---

## Rodar os testes

```bash
npm run test
```

---

## Estrutura de pastas

```bash
app/
components/
hooks/
lib/
tests/
```

---

## Sobre os testes

* Teste do componente de adicionar tarefa
* Teste do hook de contador
* Teste da página principal
